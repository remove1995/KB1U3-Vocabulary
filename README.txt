Simon’s Toy Box — финальная версия

Распакуйте архив и откройте index.html в браузере. Для начала нажмите Play.
Все изображения, шрифты, реплики, звуки игрушек и музыка включены в архив.

Для GitHub Pages загрузите содержимое архива в корень репозитория: index.html, JS/CSS, папки assets и audio. Сохраните структуру папок.

Управление:
Home — начать заново.
Динамик и нота — звук и музыка; при наведении/фокусе открываются отдельные бегунки громкости.
Круглая стрелка — повтор текущего задания.
Флешкарточка закрывается кликом.

Повторение проходит после 2-го, 4-го и 7-го предмета. Все названия — с артиклем.
